# irenelopezmoyo.com

Personal portfolio of Irene López Moyo, told as a story in three acts.

Plain HTML, CSS and JavaScript, with no build step and no dependencies.

- `index.html`: content and structure
- `styles.css`: palette, typography and layout (colour tokens at the top)
- `main.js`: scroll animations (reveal, progress bar, act rail, parallax)

## Preview locally

Open `index.html` in a browser, or run `npx serve .`

## Deploy

Any static host works (Vercel, Netlify, Cloudflare Pages, GitHub Pages). Leave the build command empty and use the repo root as the output directory.
